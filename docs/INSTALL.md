# Установка

## 1. Включить ADB

ADB позволяет ставить приложения и менять настройки телевизора по сети. Без него лаунчер не установить.

**Hartens (плата CVTE), проверено на HTY-50UHD11B-S2.** ADB включается в инженерном меню:

1. На пульте зажмите кнопку меню ☰, откроется быстрое меню настроек.
2. Не закрывая его, нажмите по очереди: ← ↑ ← ↑ →, затем «Назад».
3. В открывшемся инженерном меню выберите **other options → ADB Mode** и поставьте **On**.
4. Выйдите кнопкой «Назад». Настройка сохраняется после перезагрузки.

Больше в инженерном меню ничего не трогайте: там калибровка панели и звука.

**Другие телевизоры с YaOS.** Путь зависит от производителя. Попробуйте:

- Настройки → Об устройстве → нажмите 7 раз на «Сборка» или «Версия ПО». Появится раздел «Для разработчиков», в нём включите «Отладка по сети» или «Отладка по USB».
- Если раздела нет, ищите в интернете «инженерное меню» или «ADB» вместе с моделью телевизора.

## 2. Узнать IP телевизора

Откройте на ТВ настройки сети и подключённую Wi-Fi сеть: там будет IP-адрес вида `192.168.1.50`. Ещё его видно в приложении роутера в списке устройств.

Чтобы адрес не менялся, закрепите его за телевизором в настройках роутера (раздел DHCP, «резервирование адреса»). Иначе после перезагрузки роутера скрипты не найдут ТВ.

## 3. Установить

Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.

**Mac.** Откройте Терминал (Программы → Утилиты → Терминал) и выполните:

```
cd ~/Downloads/moy-tv-main
bash scripts/install.sh
```

**Linux.** То же самое, нужны `curl` и `unzip`.

**Windows 10 и 11.** Откройте распакованную папку, затем папку `windows`, дважды щёлкните `install.bat`. Если Windows предупредит о неизвестном файле, нажмите «Подробнее → Выполнить в любом случае».

Скрипт:

1. скачает `adb` от Google в папку `.tools` (около 15 МБ), если его нет в системе;
2. спросит IP телевизора и запомнит его в файле `.tv_ip`;
3. подключится к ТВ. В этот момент на экране телевизора появится запрос «Разрешить отладку?». Поставьте галочку «Всегда разрешать» и нажмите ОК;
4. скачает лаунчер из [Releases](../../../releases/latest) и установит его;
5. выдаст права и сделает лаунчер экраном по кнопке HOME.

## 4. Первые шаги

- **Город.** ОК на карточке погоды → «Сменить город» → наберите название → «Найти» → выберите из списка. Пока город не выбран, показывается Москва.
- **Пульт с телефона.** Ярлык «Телефон» покажет адрес вида `http://192.168.1.50:8080/?k=1234`. Откройте его в браузере телефона, подключённого к той же Wi-Fi сети. При первом нажатии кнопки ТВ ещё раз спросит разрешение на отладку: выберите «Всегда».
- **Входы HDMI.** Подписи берутся из системного меню источников: если переименовать вход там (например, в «PS5»), лаунчер покажет новое имя.
- **Порядок приложений.** Долгое нажатие ОК на плитке: остановить, скрыть, сдвинуть влево или вправо. Скрытые возвращаются через «Все приложения».

## Если что-то не так

| Проблема | Что делать |
|---|---|
| «НЕТ ПОДКЛЮЧЕНИЯ» | Проверьте, что ADB включён, ТВ и компьютер в одной сети, IP верный. Удалите файл `.tv_ip` и запустите скрипт снова, чтобы ввести IP заново |
| Запрос «Разрешить отладку?» не появился | Выключите и включите ADB Mode, запустите скрипт ещё раз |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | Стоит версия с другой подписью. Удалите её: `adb uninstall ru.mikulinskiy.tvhome` |
| По HOME открывается экран Яндекса | Запустите `install.sh` ещё раз или отключите экран Яндекса через `tweaks` (пункт 2) |
| Погода не грузится | Провайдер может блокировать один из сервисов погоды, лаунчер переключится на второй. Если не грузится никакой, проверьте интернет на ТВ |
| После обновления прошивки вернулся экран Яндекса | Прошивка сбрасывает настройки. Запустите `install.sh` и `tweaks` ещё раз |
| Пропали входы HDMI в меню источников | Вы отключили `com.yandex.tv.live` или `com.yandex.tv.input.efir`. Запустите `undo`, он их включит |

## Удалить

`bash scripts/undo.sh` (Mac, Linux) или `windows\undo.bat` вернёт экран Яндекса, включит всё отключённое и по желанию удалит лаунчер.
