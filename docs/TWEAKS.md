# Настройка YaOS

На телевизоре с 1,3 ГБ памяти после включения свободно около 470 МБ: остальное занимают Алиса, музыка, браузер и домашний экран Яндекса, даже если ими не пользоваться. После настройки ниже свободно около 640 МБ, приложения открываются быстрее.

Запуск: `bash scripts/tweaks.sh` (Mac, Linux) или `windows\tweaks.bat`. Скрипт спрашивает подтверждение по каждому пункту. Вернуть всё: `undo`.

Отключённое приложение не удаляется: оно остаётся в системе и включается обратно одной командой (`pm enable`). Обновление прошивки может включить всё обратно, тогда запустите `tweaks` ещё раз.

## Что отключается

| Пункт | Пакеты | Что потеряете |
|---|---|---|
| 1. Алиса | `com.yandex.tv.alice` | Голосовой поиск и кнопку микрофона |
| 1. Яндекс Музыка | `com.yandex.tv.music` | Приложение Музыки на ТВ |
| 1. Яндекс Браузер | `com.yandex.browser.tv` | Браузер |
| 1. Рекламный ID | `com.yandex.android.advid` | Ничего |
| 1. Заставка | `com.yandex.tv.daydream` | Заставку при простое |
| 1. Отчёты об ошибках | `com.yandex.tv.bugreportsender` | Ничего |
| 2. Домашний экран Яндекса | `com.yandex.tv.home` | Экран с рекламой и подборками. Работает только после установки «Мой ТВ» |
| 3. Анимации | системные настройки, 0.5 вместо 1 | Анимации в два раза короче |
| 4. Работа в фоне | Lampa, Prisma TV, RuStore, LostFilm New TV, Кинопоиск, SmartTube, VLC | Эти приложения не стартуют сами при включении ТВ и не держат службы в фоне. Когда вы их открываете, работают как обычно. Если какое-то перестанет обновлять каналы или докачивать, верните ему фон через `undo` |
| 5. Кэш | `pm trim-caches` | Приложения заново скачают картинки |

## Что трогать нельзя

Эти пакеты держат на себе важные функции. Если отключить, телевизор частично перестанет работать.

| Пакет | За что отвечает |
|---|---|
| `com.yandex.tv.live`, `com.yandex.tv.input.efir` | Меню источников и входы HDMI |
| `com.yandex.tv.settings` | Настройки: Wi-Fi, Bluetooth, системный таймер сна |
| `ru.yandex.androidkeyboard.tv` | Экранная клавиатура, другой на ТВ нет |
| `com.yandex.tv.services*`, `com.yandex.io.sdk` | Системные службы Яндекса, пульт |
| `com.yandex.tv.videoplayer`, `com.yandex.tv.webplayer` | Встроенные плееры |
| `com.yandex.tv.setupwizard`, `com.yandex.tv.vendor.config`, `com.yandex.server.*` | Первичная настройка и конфигурация производителя |
| `com.mediatek.*`, `com.ctv.*`, `com.cultraview.*`, `com.android.*` | Драйверы и система Android |
| `org.xwalk.core` | Движок, на котором работает Lampa |

В инженерном меню телевизора меняйте только ADB Mode.

## Что отключить не получится

- `com.yandex.io.sdk` (90 МБ памяти) и `com.yandex.launcher.updaterapp`: прошивка защищает их от отключения.
- Отдельные компоненты приложений, например автозапуск при включении: без root команда `pm disable` для них не работает. Поэтому в пункте 4 используется запрет фона через `appops`.
